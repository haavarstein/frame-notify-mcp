# frame-notify-mcp (archived)

This project has moved. Development continues in **[haavarstein/botframe-mcp](https://github.com/haavarstein/botframe-mcp)**, the BotFrame MCP server for pushing short alerts to a wall frame.

botframe-mcp builds on this code and adds per-source agent tokens, rate limits, a server-side secret filter, a required frame token for dismissing alerts, and a localhost-only default bind.

This repository is read-only. Please open issues and pull requests in botframe-mcp.
